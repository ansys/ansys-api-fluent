**Service:** **Events**

Events service provides streaming of solver and workflow events to clients.

``BeginStreaming``
   :Request: :ref:`BeginStreamingRequest <proto-events-beginstreamingrequest>`
   :Response: stream of :ref:`BeginStreamingResponse <proto-events-beginstreamingresponse>`

   Begins streaming of events; the server sends a stream of `BeginStreamingResponse` messages until the stream is closed.

``PauseSolveFor``
   :Request: :ref:`PauseSolveForRequest <proto-events-pausesolveforrequest>`
   :Response: :ref:`PauseSolveForResponse <proto-events-pausesolveforresponse>`

   The solver pauses when a selected solution event occurs.

``ResumeSolve``
   :Request: :ref:`ResumeSolveRequest <proto-events-resumesolverequest>`
   :Response: :ref:`ResumeSolveResponse <proto-events-resumesolveresponse>`

   Resumes solver execution after a pause triggered by a solution event.

``CancelPauseSolve``
   :Request: :ref:`CancelPauseSolveRequest <proto-events-cancelpausesolverequest>`
   :Response: :ref:`CancelPauseSolveResponse <proto-events-cancelpausesolveresponse>`

   Unregisters a prior pause-on-solution-event registration.
