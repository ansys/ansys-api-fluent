FixStateResponse is the response message after fixing state

``state`` (1) : :ref:`Variant <proto-variant-variant>`
   The fixed state

``deleted_paths`` (2) : repeated ``string``
   Paths of deleted objects during fix

**Enumerations**

**DiffState** *(enum)*

DiffState specifies the level of detail for state differences

``DIFF_STATE_UNSPECIFIED`` (0)
   Unspecified diff state

``DIFF_STATE_FULL`` (1)
   Full state including commands

``DIFF_STATE_NOCOMMANDS`` (2)
   State without commands

   Unspecified subscription status

``SUBSCRIPTION_STATUS_SUBSCRIBED`` (1)
   Successfully subscribed

``SUBSCRIPTION_STATUS_UNSUBSCRIBED`` (2)
