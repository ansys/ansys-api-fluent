.. _user_guide:

==========

The user guide covers practical, task-oriented workflows.

Choose an entry point based on the task you are working on:

:doc:`Session setup <client_examples/session_setup>`
   Connect to a Fluent server, check health, and inspect session/runtime
   information.

:doc:`DataModel service <client_examples/datamodel_se>`
   Explore the meshing-oriented service schema, then read state, write state,
   execute commands, and subscribe to events.

:doc:`Settings service <client_examples/settings>`
   Explore the solver-oriented service schema, then read state, write state,
   manage named objects, and call commands and queries.

:doc:`Solver streams <client_examples/solver_streams>`
   Subscribe to transcript, event, and monitor streams while a simulation runs.

:doc:`Simulation data <client_examples/simulation_data>`
   Query field data, reductions, and solution-variable payloads for
   post-processing.

:doc:`Helper types <client_examples/helpers>`
   Construct and unpack shared message types used across multiple services.
