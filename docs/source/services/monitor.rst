Monitor Service
===============

The Monitor service provides system monitoring and performance tracking capabilities.

Overview
~~~~~~~~

The ``Monitor`` service allows you to:

- Track simulation progress
- Monitor performance metrics
- Get residual and convergence information

Service Definition
~~~~~~~~~~~~~~~~~~

**Package:** ``ansys.api.fluent.v1.monitor``

**Main Classes:**

- ``MonitorStub``: Client stub for monitoring operations
