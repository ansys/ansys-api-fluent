Solver Variables Service
=========================

The Solver Variables service provides access to solver state variables and data.

Overview
~~~~~~~~

The ``SVar`` service allows you to:

- Query solver variables
- Access state data
- Monitor solver execution state

Service Definition
~~~~~~~~~~~~~~~~~~

**Package:** ``ansys.api.fluent.v1.svar``

**Main Classes:**

- ``SVarStub``: Client stub for solver variable operations
