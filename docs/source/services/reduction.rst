Reduction Service
=================

The Reduction service provides data reduction and compression capabilities.

Overview
~~~~~~~~

The ``Reduction`` service allows you to:

- Reduce mesh complexity
- Compress field data
- Optimize data for transmission

Service Definition
~~~~~~~~~~~~~~~~~~

**Package:** ``ansys.api.fluent.v1.reduction``

**Main Classes:**

- ``ReductionStub``: Client stub for reduction operations
