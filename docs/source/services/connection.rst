Connection Service
==================

The Connection service manages connections to Fluent servers.

Overview
~~~~~~~~

The ``Connection`` service provides:

- Connection establishment and management
- Connection status tracking
- Remote connection handling

Service Definition
~~~~~~~~~~~~~~~~~~

**Package:** ``ansys.api.fluent.v1.connection``

**Main Classes:**

- ``ConnectionStub``: Client stub for connection operations
