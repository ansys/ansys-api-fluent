Meshing Queries Service
========================

The Meshing Queries service provides mesh-related queries and operations.

Overview
~~~~~~~~

The ``MeshingQueries`` service allows you to:

- Query mesh properties
- Get mesh statistics
- Mesh diagnostics

Service Definition
~~~~~~~~~~~~~~~~~~

**Package:** ``ansys.api.fluent.v1.meshing_queries``

**Main Classes:**

- ``MeshingQueriesStub``: Client stub for mesh queries
