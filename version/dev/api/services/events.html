Service: Events

Events service provides streaming of solver and workflow events to clients.

BeginStreaming
Request:

BeginStreamingRequest

Response:

stream of BeginStreamingResponse

Streams solver events to the client.

PauseSolveFor
Request:

PauseSolveForRequest

Response:

PauseSolveForResponse

Registers a solution-event pause trigger; the solver pauses when the selected event occurs and waits until the client calls ResumeSolve.

ResumeSolve
Request:

ResumeSolveRequest

Response:

ResumeSolveResponse

Resumes solver execution after it was paused by a PauseSolveFor trigger.

CancelPauseSolve
Request:

CancelPauseSolveRequest

Response:

CancelPauseSolveResponse

Unregisters a pause trigger previously registered with PauseSolveFor.
