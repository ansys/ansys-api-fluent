Service: FieldData

FieldData service provides methods for retrieving field and surface data from Fluent simulations.

Response:

Configures and initiates a server-streaming field data session. The request sets the chunk size and encoding format (bytes or typed arrays); the server streams BeginFieldsStreamingResponse chunks back until all requested field data has been delivered.
