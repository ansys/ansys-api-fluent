Service: ApplicationRuntime

ApplicationRuntime service provides methods that span the Fluent application lifecycle but do not belong to a domain-specific service. Typical uses include retrieving version and build metadata, managing feature flags, and controlling application startup and shutdown.

StartPythonJournalRequest

Initiates a Python journal recording session.

journal_name (1)oneof _journal_name string

Optional journal output file name.

If set, the journal is written to this file on the server side. If not set, the journal text can be retrieved from StopPythonJournal.

StartPythonJournalResponse

Contains the result of starting a Python journal.

journal_id (1)oneof _journal_id string

Optional journal identifier.

Returned when no journal file name was provided and the journal is tracked in-memory/session state. Provide this id to StopPythonJournal to stop the correct recording session.

StopPythonJournalRequest

Terminates a Python journal recording session.

journal_id (1)oneof _journal_id string

Optional journal identifier to stop.

Required when StartPythonJournal did not provide a file name and returned a journal_id.

StopPythonJournalResponse

Contains the result of stopping a Python journal.

journal_str (1)string

Journal content.

Typically populated when StartPythonJournal did not specify a file name. If the journal was written to a file, this string may be empty (server-defined behavior).
